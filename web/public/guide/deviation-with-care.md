# 偏差値（編集推計）との付き合い方

偏差値は、学力の目安を考えるための一つの材料です。ただし、学校の良さや本人との相性を一つの数字だけで決めるものではありません。Manabi Map に掲載する値も、公的資料を参考にした編集推計であり、公式の合格判定ではありません。

## 数字だけでは分からないこと

同じ学校でも、学科・年度・選抜方法によって状況は変わります。募集要項、学びたい内容、校風、部活動、通学、費用、支援体制など、数字に表れないことも進路選択では大切です。

数値が掲載されていない学校は、価値が低いという意味ではありません。根拠を確認できない値は載せないという方針です。学校の公式サイト、説明会、教育委員会の資料などで、必要な情報を一つずつ確かめてください。

## 使うときの3つの約束

1. 一つの数値で候補を決めず、気になる学校を広く見てみる
2. 模試や学校の成績は、その時点の学習を考える材料として使う
3. 出願や合格の判断は、学校・教育委員会・進路指導の先生が示す最新情報を確認する

## 親子で話すための材料にする

数字を見たときは、「この学校で何を学びたいか」「一日の生活を続けられそうか」「見学で何を感じたか」と一緒に並べてみてください。本人が大切にしたいことを言葉にすると、候補の比較がしやすくなります。

Manabi Map の編集推計の根拠、掲載範囲、限界は、[偏差値の方法と限界](https://manabi-map.app/legal/deviation-methodology) で公開しています。数値を使う前に、必ず確認してください。
