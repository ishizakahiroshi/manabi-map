# 通学時間と通学範囲の考え方

学校を選ぶとき、毎日の移動は授業や部活動と同じくらい生活に影響します。まずは「続けられる一日になるか」を、本人と家族で具体的に想像してみましょう。

## 最初に: 地図の直線距離は目安です

地図上の直線距離は、学校の位置を比べるための目安にすぎません。実際の通学時間は、駅やバス停までの移動、乗り換え、道路や坂、始業時刻、悪天候などで大きく変わります。地図の数字だけで通える・通えないを決めず、候補が絞れたら実際の経路を確認してください。

## 一日の流れで考える

- 家を出る時刻と、朝食・身支度に必要な時間
- 登校後の待ち時間、放課後の部活動や補習が終わる時刻
- 帰宅後に食事、宿題、休息を取れる余白
- 早朝や夜間、雨の日、冬の時期にも無理がないか

平日だけでなく、文化祭準備や大会前など帰宅が遅くなる日のことも聞いてみると、学校生活の輪郭が見えやすくなります。

## 確認の順番

1. 学校の公式サイトや募集要項で、登校時刻・行事・部活動の情報を確認する
2. 地図アプリや交通機関の案内で、朝と帰宅時間帯の経路を調べる
3. 可能なら実際に同じ時間帯で移動し、乗り換えや歩く道を確かめる
4. 本人の感想を、疲れ方や安心できる点も含めてメモに残す

Manabi Map では、気になった学校ごとに家族の見学メモや通学経路の感想を残せます。数値ではなく、実際に確かめたことを比較材料にしてください。

## 最後に

通学範囲に正解はありません。学校で過ごしたい時間、家庭での生活、体力や安全面を一緒に考え、その家庭にとって続けやすい選択を探していきましょう。
