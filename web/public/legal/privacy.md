## 2. 収集する情報

本サービスは、以下の情報を収集・保存する場合があります。

- **LINE 認証情報**: LINE の認証で扱う provider user ID・表示名
- **Google 認証情報**: Google OAuth で認証する際に Google から提供される provider user ID・email・display name 等の profile 情報。Supabase Auth のユーザー／セッション情報として扱い、アプリ独自の学校データとして保存・公開するものではありません
- **匿名認証の UUID**: 匿名で利用する場合に発行される識別子。匿名利用のデータを紐付けるために使います
- **設定地点**: 地図検索のために入力された住所・地名等から得た地点。これは「自宅住所」ではなく、地図表示の**「設定地点」**として扱います。保存時は住所の文字列を保存せず、ラベルを「設定地点」に統一し、緯度・経度をそれぞれ小数第 3 位までに丸めた値をブラウザの localStorage に保存します。認証セッションがある場合は同じ値を Supabase の `home_locations` に保存します
- **お気に入り・メモ・個人偏差値記録**: 利用者が本サービス上で登録した学校のお気に入り、自由メモ、個人的な偏差値の記録
- **学校情報の提供・訂正報告**: 利用者が送信した値、出典、補足コメント、匿名認証を含む送信者 UUID。個人情報・答案画像は送らないでください

個人メモは本人（および明示的に共有を許可した相手）だけが閲覧でき、公開データに混ざることはありません。

## 3. 利用目的

収集した情報は、以下の目的で利用します。

- LINE・Google・匿名の認証状態の維持、利用者ごとのデータ（お気に入り・メモ等）の保存と表示
- 本サービスの提供・維持・改善
- 学校情報の正確性を改善するための報告の受付・資料確認・対応履歴の管理
- 設定地点を使った地図表示、通学距離・所要時間の計算

学校情報の提供・訂正報告は、運営が出典を確認してから公開データへの反映を判断します。報告値が送信直後に表示へ反映されることはありません。報告データは本人確認や運営上の問い合わせ対応に必要な期間保管し、削除・訂正のご要請に対応します。

収集した個人情報を、本人の同意なく第三者へ提供・販売することはありません。

## 4. Cookie・ローカルストレージ・アクセス解析

- 認証セッション維持のために**ローカルストレージ**を使用します。
- 設定地点は、住所の文字列を保存せず、ラベル「設定地点」と小数第 3 位までに丸めた緯度・経度を localStorage に保存します。認証セッションがある場合は Supabase の `home_locations` にも同じ値を保存します。
- **広告目的の Cookie・トラッキングは一切使用しません。**
- アクセス解析には **Cloudflare Web Analytics（Cookie レス）のみ**を利用します。個人を追跡する Cookie は使用しません。

### 4.1 サービス内の行動ログ（クッキーレス）

本サービスの改善のために、サービス内での操作を**匿名の行動ログ**として記録することがあります。

- **クッキーは使用しません。** 匿名の利用単位（セッション識別子）は端末の**ローカルストレージ**にのみ保存され、広告目的では利用しません。
- 記録するのは「どの操作が行われたか」だけです。具体的には、地図検索の実行・学校詳細の表示・お気に入り登録・メモ保存・学校比較・広告リンクのクリックといった**操作の種類**と、対象となった**学校の識別子・所在都道府県**、集計用の件数などに限られます。
- **住所そのもの・氏名・LINE／Google の表示名・email・provider user ID・設定地点の緯度経度といった情報は、行動ログには含めません**（システム上、そうした値がログに載らない設計にしています）。
- 記録した行動ログは**日次の集計値としてのみ**参照します。**個別の利用者がいつ何を見たかという記録は、運営者もアプリを通じて閲覧できない設計**にしています（未成年の利用を想定しているための配慮です）。
- お気に入り・メモといった保存データそのものの扱いは第 2 節・第 6 節・第 7 節のとおりで、削除のご要請にも対応します。

## 5. 偏差値データについて

本サービスの偏差値は「**Manabi Map 編集推計**」であり、公的資料を参考にした編集推計の参考情報です。**他社の商用サイトからのデータ転載は行っていません。** 正確性は保証されず、あくまで目安としてご利用ください（詳細は利用規約 第4条・[推計の方法と限界](/legal/deviation-methodology)）。

## 5.5 広告表示について <a id="ads"></a>

本サービスは、運営維持のために **進路・教育に関係する広告のみ**を、控えめに表示することがあります。

- 表示する広告は、**学習塾・予備校・個別指導・通信制高校・大学・専門学校・通信教育・模試** など、進路検討に関係するもののみです。
- 消費者金融・ギャンブル・アダルト・情報商材・出会い系など、進路と無関係な広告は表示しません。
- **Google AdSense をはじめとする無差別アドネットワーク（内容を選ばず自動配信されるディスプレイ広告）は使用していません。** 広告枠は運営者が手動で選定した案件のみを掲載します。
- モーダル・インタースティシャル・自動再生動画・追従バナーなど、利用体験を損なう形式は使用しません。
- 広告カードには「PR」ラベルを付けて、広告であることを明示します。
- 広告リンクを開いた際、遷移先 URL に **UTM パラメータ**（`utm_source=manabi-map` 等）が付与されます。これは掲載効果の集計目的で使用するもので、**個人を識別できる情報を広告主に共有することはありません。**
- 広告目的の Cookie・トラッキングは行いません（第 4 節参照）。

NPO・自治体連携版などでは広告全 OFF での提供を想定しています。

## 6. 情報の削除・訂正のご要請

保存された個人情報の削除・訂正をご希望の場合は takedown@manabi-map.app までご連絡ください。

学校情報の提供・訂正報告に含めた情報の削除・訂正をご希望の場合も、同じ窓口で受け付けます。

- ご要請の受理から **24 時間以内に受信確認**を返信します。
- **7 日以内に対応**します。

## 7. アカウントの削除

利用者のご依頼により、本サービスが保有する当該利用者の個人データを削除または個人との紐付けを外します。LINE・Google・匿名認証のいずれの場合も対象です。ご希望の際は takedown@manabi-map.app までご連絡ください。

削除対象は、Supabase Auth の当該アカウントと provider 連携、設定地点、お気に入り、メモ、個人偏差値記録、家族グループ・メンバー情報など、当該アカウントに紐づくデータです。学校情報の提供・訂正報告の本文や対応履歴、集計済みの行動ログは、運営上必要な範囲で送信者 UUID・ユーザー ID との紐付けを外して残る場合があります。ブラウザに残る localStorage の設定地点や認証セッションは、利用者がブラウザの本サービスのサイトデータを削除することでも消去できます。

## 8. 未成年者のプライバシー

本サービスは中高生の進路検討での利用を想定しています。未成年の方は、**保護者の方と一緒に利用する**ことを推奨します。子どもの個人情報を過度に入力させない設計を基本方針としています。

## 9. データの保管・委託

本サービスは認証・データ保存に Supabase、ホスティングに Cloudflare Pages を利用しています。Supabase は認証（LINE の Custom OIDC、Google OAuth、匿名認証を含む）とデータベース保存を担います。Google は OAuth の identity provider として認証情報を提供し、LINE は Custom OIDC の identity provider として認証情報を提供します。これらのサービス提供者に、上記目的の範囲で情報の保管・処理を委託する場合があります。各社が扱う情報や保持期間の詳細は、各社のポリシー・規約によります。

## 10. 準拠法・管轄

本ポリシーは日本法に準拠します。関連して紛争が生じた場合は、運営者の所在地を管轄する地方裁判所を第一審の専属的合意管轄裁判所とします。
