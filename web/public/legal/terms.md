## 2. サービスの内容

本サービスは、高校などの学校情報を地図上で確認し、お気に入り登録・メモ・偏差値の記録などができる無料の Web アプリです。進路検討の「入口」として使っていただくことを目的としています。

本サービスは営利を目的としません。物品・デジタルコンテンツの販売は行っておらず、現時点では寄付も受け付けていません。そのため特定商取引法に基づく表記の対象外です。

## 3. アカウントと認証

本サービスは以下の 3 通りの方法で利用できます。

- **LINE でログイン**: LINE の Custom OIDC 認証情報（provider user ID・表示名等）を利用します
- **Google でログイン**: Google OAuth の認証情報（provider user ID・email・display name 等の profile 情報）を Supabase Auth 経由で利用します。Google と LINE は別のログイン方法であり、通常は自動的に同じアカウントへ統合されません
- **匿名で試す**: 端末ごとに発行される匿名 UUID を利用します（アカウント登録は不要です）

匿名利用中のデータ（設定地点、お気に入り・メモ等）は匿名 UUID に紐付けて Supabase に保存されます。匿名利用中に LINE または Google を連携すると、同じ Supabase ユーザーのまま認証方法を追加し、匿名利用中のデータを引き継げます。ただし端末やブラウザのデータを消去するとログイン状態が失われ、連携前の匿名データにアクセスできなくなる場合があります。

設定地点は、住所の文字列を保存せず、ラベルを「設定地点」に統一し、緯度・経度をそれぞれ小数第 3 位までに丸めて保存します。ブラウザの localStorage に保存し、認証セッションがある場合は Supabase の `home_locations` にも保存します。

## 4. 偏差値・学校情報の取り扱い

本サービスに掲載する偏差値は「**Manabi Map 編集推計**」であり、都道府県教育委員会の入試結果・学校公式広報・文部科学省の学校基本調査などの**公的資料を参考にした編集推計の参考値**です。公式偏差値・合格判定ではありません。掲載基準・方法・限界は[「推計の方法と限界」](/legal/deviation-methodology)で公開しています。

- **他社の商用サイトからのデータ転載・スクレイピングは一切行っていません。**
- 偏差値はあくまで目安であり、正確性・完全性・最新性を保証するものではありません。
- 実際の入試難易度・合否は各学校・塾・公的資料でご確認ください。
- 学校名・住所・公式情報などについても、正確性を保証するものではありません。

本サービスの情報に基づいて利用者が行った判断・行動について、運営者は責任を負いません。

### 4.1 学校情報の提供・訂正報告

利用者は、学校公式・教育委員会などの一次資料に基づく情報を、提供・訂正報告フォームから送信できます。報告値は自動公開せず、運営者が資料を確認したうえで反映を判断します。個人情報、他人の情報、答案画像、商用サイトから転載した値は送信しないでください。

LINE・Google・匿名のいずれで利用した場合も、利用者から takedown@manabi-map.app へご依頼いただけます。削除対象は Supabase Auth の当該アカウントと provider 連携、設定地点、お気に入り、メモ、個人偏差値記録、家族グループ・メンバー情報など、当該アカウントに紐づくデータです。学校情報の提供・訂正報告の本文や対応履歴、集計済みの行動ログは、運営上必要な範囲で個人との紐付けを外して残る場合があります。詳細はプライバシーポリシーをご覧ください。
